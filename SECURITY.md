# Security policy

If you find a vulnerability, please do not open a public issue. Email luceroriosg@gmail.com with the details and steps to reproduce. You will get a reply within a few days.

Scope: the code in this repository and the demo at https://cv-stress-test.vercel.app. The app stores nothing server side; CV and job description text is sent to the configured model providers (Groq, NVIDIA NIM) to produce the evaluation.
